# web-template-front

Vue 3와 Vite로 만든 프런트엔드 프로젝트입니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

터미널에 표시되는 주소로 접속하면 됩니다. 기본 주소는 `http://localhost:3100`입니다.

## 자주 쓰는 명령어

```powershell
# 개발 서버 실행
npm.cmd run dev

# 배포용 빌드
npm.cmd run build

# 빌드 결과 미리보기
npm.cmd run preview
```

PowerShell 실행 정책으로 `npm` 실행이 막히면 `npm.cmd`를 사용하세요.
